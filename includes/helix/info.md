#### Appearance

Helix comes with several dozen themes. If only the builtin "default" and "base16_default" themes are available, that means Helix cannot access the color themes.
The **runtime** directory containing the color themes must exist as sibling to the executable.

Color themes are specified in configuration using the `theme` keyword

```toml
theme = "catpuccin_mocha"
```
