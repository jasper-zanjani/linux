This simple example shows how to incorporate the **fontspec** package into a small macro.

```latex title="fontspec/01" hl_lines="8"
--8<-- "includes/latex/study/fontspec/01/doc.tex"
```

A custom command can be defined to format long division problems:

```latex hl_lines="3-5"
--8<-- "includes/latex/tasks/long-division.tex"
```
