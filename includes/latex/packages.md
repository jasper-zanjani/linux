*[CTAN]: Comprehensive TeX Archive Network

Packages (with filenames ending in **.sy**) are available on [CTAN](https://ctan.org).
A few packages are commonly used to handle layout and styling

- **fontspec** to use system fonts easily
- **geometry** to set page margins
- **hyperref**
- **titlesec** to format document sections
- **enumitem** to change the appearance of lists
