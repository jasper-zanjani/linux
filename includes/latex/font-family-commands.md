There are several font families in LaTeX: Roman (default), sans serif, and typewriter (monospace).
Font family can be set by one of two sets of commands:

-  **commands** delimit the text to be styled with braces (i.e. `\texttt{}`)
-  **declarations** or **switches** change the style from that point to the end of the document, unless another switch is used (i.e. `\ttfamily`).
